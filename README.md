AI-Powered Apparel Product Recommender
Product similarity recommendation engine in the e-commerce platform using vector embeddings (Llama models) stored in MongoDB.

Capabilities :

Vector Similarity Search
by image
by text
Multiple vector indexing types
Hybrid Queries
Apply tags as pre-filter for vector search

Analyzes past purchase history (from AstraDB vector search)
Asks clarifying questions about the occasion, weather, personal style
Searches similar styles using vector similarity
Creates complete outfit recommendations with reasoning
Adapts suggestions based on real-time feedback
